# Slide Race

A simple derivative game for students. Open `index.html` in any browser (no install).

## Files
```
index.html
css/style.css
js/math.js   the derivative rules (Constant, Power, Constant Multiple, Sum/Difference)
js/app.js    score, race, practice
```

Every file has comments explaining what each part does. Good places to start when explaining:
`js/math.js` (the rules) and the "RACE TAB" section of `js/app.js`.

## How it works
- **Race:** two balls roll down two slides. Each ball has a distance formula (like s = t² + 3t).
  Predict which ball is going faster at 3 seconds, then watch the race. The answer shows how the
  four rules turn the distance formula into a speed formula.
- **Practice:** pick the correct derivative from 4 choices. Each answer shows the rules step by step.

Right answers give 10 points.
